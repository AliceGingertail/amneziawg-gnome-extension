# AmneziaWG GNOME Shell Extension

Control AmneziaWG and WireGuard from GNOME Quick Settings: select a saved server,
connect, and disconnect without opening the AmneziaVPN app.

Requires the installed AmneziaVPN service and a server configuration prepared
by connecting once in the app. English and Russian translations are included;
the interface follows your GNOME session language.

Open preferences from the extension menu or run:

```sh
gnome-extensions prefs amnezia@example.com
```

> [!WARNING]
> Xray is not supported.
> A temporary solution for suspend and hibernate is to reconnect using the button event
